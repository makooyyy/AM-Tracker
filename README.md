## Major 100 — Ночь историй и новые открытия

## Премия года — зал славы

Во вкладке **Премия → Год** собраны лидеры сезона, пьедестал, победители номинаций и календарь из 12 месяцев. Каждая положительная награда месяца даёт один балл; антипремии не учитываются, одинаковые результаты делят место. Текущий год показывает промежуточные итоги. Карточки открывают сохранённые данные победителей, календарь — премию выбранного месяца.

Средняя оценка года рассчитывается по последней сохранённой оценке каждого тайтла именно за этот год.

## Первые шаги

### Коллекции, перечитывание и личная витрина

Коллекции переключаются в компактной полосе над библиотекой. Продолжение чтения, выбор нескольких тайтлов, сравнение, управление коллекциями и корзина находятся в «⋯ Ещё» рядом с поиском. Повторное нажатие на выбранную коллекцию снимает фильтр. В режиме «Выбрать несколько» нажатие на обложку выделяет тайтл; количество выбранных и раскрываемая панель действий закреплены снизу.

Кнопка «Оценить главу» рядом с прогрессом открывает небольшую панель. Черновики текста, оценки и отметки спойлера автоматически сохраняются локально и восстанавливаются после перезагрузки. Они не синхронизируются между устройствами и очищаются при очистке данных аккаунта. Доступны действия «Продолжить в панели» и «Удалить черновик».

Над дневником можно выбрать прочтение: меняются записи, график и показанный прогресс. Архив доступен для просмотра и удаления записей; новые записи добавляются в текущее прочтение. Для повторно оценённых глав показано изменение относительно предыдущего прохода.

Сравнение выделяет более высокие оценки по критериям, разницу и общие жанры. Названия тайтлов остаются над таблицей при прокрутке. В редакторе витрины есть живой предпросмотр и кнопки изменения порядка; окончательное применение — после сохранения профиля. В магазине «Примерить» не списывает монеты, «Купить» выполняет покупку, приобретённые предметы отмечены «Уже в коллекции».

- В библиотеке можно создать до 40 своих коллекций. Тайтл может быть на нескольких полках. Переименование и удаление коллекции не удаляют сами тайтлы.
- «Выбрать несколько» включает массовые действия: статус, добавление жанра, добавление в коллекцию или исключение из неё, перенос в корзину. «Выбрать видимые» учитывает поиск и фильтры.
- Корзина хранит до 20 тайтлов без автоматического удаления. При заполнении или превышении безопасного размера операция отклоняется — сначала освободи место. Восстановление возвращает записи, оценки и принадлежность к коллекциям. Окончательное удаление требует подтверждения. Последнее удаление записи дневника можно отменить до перезагрузки страницы.
- В карточке тайтла, в «Коллекции и перечитывание», можно начать новое прочтение. Номер главы сбрасывается в 0, прежние записи остаются в истории. В новом проходе можно заново оценить ту же главу; в пределах одного прохода по-прежнему разрешена одна оценка главы. Общая оценка тайтла сохраняется — для её изменения используется переоценка.
- «Сравнить» в библиотеке открывает два тайтла рядом: личный балл, критерии, жанры и средняя оценка глав текущего прочтения. Из дуэли сравнение открывается с уже выбранной парой.
- В редакторе профиля раздел «Моя витрина» позволяет закрепить до трёх тайтлов, полученное достижение и принадлежащее пользователю украшение. Кнопка «Сохранить витрину» сохраняет выбор вместе с текущими изменениями профиля. Редактор закрывается только после завершения записи на устройство; при ошибке остаётся открытым для повторной попытки. Тема, рамка и значок выбираются в компактной Студии профиля; эмодзи и сохранённые образы находятся в раскрывающихся разделах.

Коллекции, витрина, корзина и история прочтений входят в резервную копию и синхронизацию.

**Дневник чтения.** В карточке тайтла доступны быстрый переход к последней записи, поиск по номеру главы, сортировка и график оценок. Нажатие на точку открывает запись, сохраняя спойлер скрытым. Для одной главы разрешена одна оценка и несколько текстовых заметок. Балл можно только удалить вместе с записью. Старые дубли сохранены; на графике используется самая ранняя оценка главы.

**Оценки и рекомендации.** Критерии видны сразу, первая оценка и переоценка требуют подтверждения перед сохранением. Эмоция остаётся отдельным впечатлением. В рекомендациях можно выбрать «Не интересно», «Уже читал» или «Больше похожего», а затем отменить последний выбор. Эти отметки сохраняются в профиле, но не добавляют тайтлы в библиотеку и не меняют оценки.

**Магазин.** Фильтры «Хватает монет», «Не куплено» и «Моя коллекция» дополняют категории и редкость. Предметы можно сортировать по цене. После покупки доступен переход к редактору профиля; оформление применяется только после выбора и сохранения в редакторе.

Прогресс чтения вводится вручную: кнопка +1 и дневник обновляют номер главы. Ссылка открывает выбранный сайт, автоматического считывания истории с читалки нет.

В **Настройки → Облик приложения** доступны «По сезону», «Классический» и «Ночь историй». По умолчанию используется сезонный режим: во время Хэллоуина включается праздничное оформление, после 2 ноября возвращается обычное. Явно выбранный облик сохраняется на устройстве и доступен независимо от дат события. Украшения профиля и задания от переключения внешнего вида не меняются.

**«Для тебя → Хэллоуин»: Ночь историй, 18 октября — 2 ноября 2026.** Шесть заданий по чтению и финальная награда за весь набор: две темы, две рамки, три значка эксклюзивной редкости, всего 800 XP и 800 монет. Участие бесплатное, прогресс считается автоматически по датам сохранённых действий; все дни события — по времени устройства. Для записей и оценок глав учитываются уникальные главы. Награды выдаются один раз, синхронизируются и остаются после события. Оформление применяется в редакторе профиля. После 2 ноября раздел становится архивом, новые награды не выдаются.

Во вкладке **«Каталог»** можно искать тайтлы и открывать их карточки. Доступны обложка, жанры, описание, рейтинг AniList и число глав, если оно известно. Кнопка «Добавить в библиотеку» переносит тайтл с выбранным статусом; рейтинг AniList не становится личной оценкой. Уже сохранённые тайтлы помечены «В библиотеке». Поиск требует интернета; результаты подгружаются по мере прокрутки. Русские названия есть не у всех произведений — попробуй английское или оригинальное название. При достижении ограничения глубины каталога уточни фильтры или запрос.

В разделе **«Премия → Год»** после завершения выбранного года появляется личная годовая сводка с сохранением в PNG. Для текущего года она открывается с 1 января следующего года. Он показывает завершённые тайтлы, выполненные цели, полученные XP и монеты, лучший тайтл и главу. Главы считаются по записям дневника, а статистика — по сохранившейся истории; удалённые старые записи могут не попасть в отчёт.

В **редакторе профиля** можно запомнить до шести образов с названием: аватар, тему, рамку и значок. Выбор образа меняет черновик; кнопка «Сохранить» применяет его. Образы входят в резервную копию и синхронизацию аккаунта.

В **магазине → Коллекции оформления** собраны пять комплектов. Видно, сколько вещей уже куплено и сколько монет нужно на оставшиеся. Примерка показывает весь набор без покупки; предметы приобретаются отдельно, а применяются в редакторе профиля.

1. **Добавь тайтл.** Введи название и выбери тип. Обложку, жанры и часть альтернативных названий можно найти через AniList или заполнить вручную.
2. **Запиши впечатление.** Выбери от одной до пяти звёзд, затем оцени отдельные критерии. Звёзды отражают эмоцию и не влияют на итоговый балл.
3. **Заверши оценку.** Добавь заметку и нажми «С рецензией» или «Без рецензии».
4. **Выбери кандидатов.** На странице оценённого тайтла отметь номинации в блоке «Кандидат в премию».
5. **Подведи итоги.** Во вкладке «Премия» выбери победителей прошедшего месяца.

> Для библиотеки и оценок аккаунт не нужен. Войти можно позже, когда понадобится синхронизация между устройствами.

## Как считается оценка

Основные критерии: **рисовка, сюжет, персонажи, темп/ритм и атмосфера**. Каждый оценивается от **1 до 10** с шагом **0,5**.

```text
Итог = среднее основных критериев × 10

Например: (8 + 9 + 7 + 8 + 9) / 5 × 10 = 82 / 100
```

- Итог отображается с округлением до целого числа.
- Если все имеющиеся критерии равны 1, итог — **1 / 100**.
- Дополнительные критерии не влияют на итог, пока остаётся хотя бы один основной. Если удалить все основные, используется среднее дополнительных.
- Неоценённые тайтлы помечены **«Не оценено»** и не входят в средний рейтинг, топ и диаграмму средних оценок.

### «Изменить» и «Оценить заново»

| Действие | Когда использовать | Что происходит |
| --- | --- | --- |
| **Изменить** | Исправить текущую карточку или оценку | Правки сохраняются в текущей записи; новая версия оценки не создаётся. |
| **Оценить заново** | Прочитал новые главы или изменил мнение | Открывается отдельный черновик. После «Сохранить переоценку» старая оценка попадает в историю. |

Черновик переоценки сохраняется **только на текущем устройстве**: к нему можно вернуться после выхода из карточки или перезапуска приложения. «Отменить переоценку» удаляет черновик и оставляет прежнюю оценку. Если данные тайтла изменились на другом устройстве, приложение попросит начать переоценку заново.

## Своя премия

Восемь номинаций: **тайтл месяца, худший тайтл месяца, рисовка, сюжет, персонажи, темп/ритм, атмосфера и обложка**.

Кандидатов и победителей выбираешь ты. Участие в месяце определяется датой текущей оценки: после переоценки тайтл участвует в новом месяце. Месячный экран показывает предыдущий календарный месяц.

После выбора всех доступных победителей можно **один раз за месяц** сбросить выбор победителей для повторной правки. В итогах года тайтлы ранжируются по количеству месячных побед; антипремия «Худший тайтл» в этот подсчёт не входит.

## Установка и работа офлайн

Открой [AM Tracker](https://makooyyy.github.io/AM-Tracker/) в браузере. Если браузер поддерживает установку PWA, используй пункт **«Установить приложение»** или **«Добавить на главный экран»** в его меню.

После первого успешного открытия с интернетом основные файлы кэшируются для работы офлайн. Локальная библиотека и оценки остаются доступны без сети. Для поиска AniList, загрузки внешних обложек, входа и обмена данными с облаком нужен интернет.

## Сохранение и синхронизация

Данные хранятся на устройстве в **IndexedDB**. Если это хранилище недоступно при запуске, приложение использует **localStorage**.

При входе по почте и паролю или через Google подключается синхронизация Firebase:

- Тайтлы, оценки, история, награды, профиль и прогресс передаются между устройствами.
- Для одного тайтла при конфликте применяется более поздняя правка; удаления тоже синхронизируются.
- XP объединяется по **максимальному значению**, достижения и журнал действий — объединением записей.
- При первом входе библиотека объединяется с облачной. Если в аккаунте уже есть профиль, загружается его облачная версия.
- Выход из аккаунта оставляет локальные данные на устройстве.

Изменения отправляются автоматически после короткой паузы. Получение обновлений происходит также при возвращении в приложение и периодически, пока оно открыто. В профиле есть кнопка **«Синхронизировать»** для ручного запуска.

Если локальная запись завершилась ошибкой, приложение покажет **«Повторить сохранение»**. Дождись успешной записи перед закрытием приложения.

### Резервная копия

В профиле выбери **«Сохранить в файл»**, чтобы скачать JSON с библиотекой, историей оценок, наградами, журналом действий, XP, достижениями и профилем.

**«Загрузить из файла»** восстанавливает данные из резервной копии. Импорт заменяет текущую библиотеку; для непустого списка приложение запрашивает подтверждение. Незавершённые черновики переоценки в резервную копию не входят.

## Запуск своей копии

Проект написан на обычных **HTML, CSS и JavaScript**. Сборка и установка зависимостей для приложения не требуются.

```bash
git clone https://github.com/makooyyy/AM-Tracker.git
cd AM-Tracker
```

Для отдельной копии сначала укажи свой Firebase-проект по инструкции ниже или отключи аккаунты в `firebase-config.js`:

```js
window.AM_FIREBASE_CONFIG = {};
```

Затем запусти любой локальный HTTP-сервер. Например, если установлен Python:

```bash
python -m http.server 8000
```

Открой **http://localhost:8000**. Для PWA используй localhost при разработке и HTTPS при публикации.

<details>
<summary><strong>Настройка Firebase для своей копии</strong></summary>

1. Создай проект в [Firebase Console](https://console.firebase.google.com/) и зарегистрируй веб-приложение.
2. Перенеси его параметры в `firebase-config.js`:

   ```js
   window.AM_FIREBASE_CONFIG = {
     apiKey: "YOUR_API_KEY",
     authDomain: "YOUR_PROJECT.firebaseapp.com",
     projectId: "YOUR_PROJECT",
     appId: "YOUR_APP_ID"
   };
   ```

3. В Firebase Authentication включи вход **Email/Password** и, при необходимости, **Google**.
4. Добавь домен своей копии в разрешённые домены Authentication.
5. Создай базу Cloud Firestore и опубликуй правила из [`firestore.rules`](firestore.rules).
6. Войди в один аккаунт на двух устройствах и проверь передачу тестового тайтла через «Синхронизировать».

Правила в репозитории разрешают пользователю читать и изменять только собственные документы в `users/{uid}/items`. Параметры веб-приложения в `firebase-config.js` видны клиенту; доступ к данным контролируется правилами Firestore.

</details>
