# Эксклюзив «Свободное падение»

Создан встроенным image_gen по референсу аватарки. Оригиналы PNG сохранены локально, WebP используются в приложении. Значок owner выполнен средствами интерфейса.

Комплект не продаётся. Доступ в интерфейсе определяется подтверждённым Firebase email, сравниваемым по SHA-256. Это косметическое оформление, не роль администратора и не серверное право доступа. Файлы изображений публичны; клиентскую проверку можно обойти модификацией приложения. Значок не даёт доступа к чужим данным. После выхода оформление скрывается; выбранные ID сохраняются для следующего входа владельца. Импорт покупок не выдаёт эксклюзив.
